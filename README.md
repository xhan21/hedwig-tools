# Hedwigとつくる道具

**日本語** | [English](README.en.md)

**授業や日々の作業で感じた「こんな道具がほしい」を、Hedwig（ChatGPT）と形にするシリーズです。**

## 作品一覧

| 作品・公開ソース | できること | 使う場所 |
| --- | --- | --- |
| [Quillo（クイロ）](https://github.com/xhan21/quillo) | 話した内容の翻訳字幕と、スライドの翻訳済み要約を別パネルに表示 | Macアプリ |
| [授業資料 翻訳ツール](https://github.com/xhan21/class-material-translator) | CanvaやClassroom・Google DriveのPDFを読み取り、訳文を別パネルに表示 | Chrome ＋ Tampermonkey |

使い方・導入方法・動作画面は、各作品のページをご覧ください。

## このシリーズの作り方

- **韓**：作りたいものを考え、仕様や修正を指示します。
- **Hedwig（ChatGPT）**：助手として、コードを生成・修正します。Hedwigは、韓が使うChatGPTの呼び名です。

開発方法の説明は、このページにまとめています。
