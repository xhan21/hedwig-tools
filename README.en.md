# Tools made with Hedwig

[日本語](README.md) | **English**

**A collection of tools made with Hedwig (ChatGPT), inspired by everyday needs in teaching and work.**

## Projects

| Project and source code | What it does | Platform |
| --- | --- | --- |
| [Quillo](https://github.com/xhan21/quillo) | Displays translated speech captions and translated slide summaries in separate floating panels | Mac app |
| [Class Material Translator](https://github.com/xhan21/class-material-translator) | Reads Canva materials and PDFs from Classroom or Google Drive, and displays translations in a separate panel | Chrome + Tampermonkey |

See each project's page for setup instructions, usage, and screenshots.

## How these tools are made

- **Han** defines the ideas and requirements and directs revisions.
- **Hedwig (ChatGPT)** generates and revises the code as an assistant. Hedwig is Han's nickname for ChatGPT.

This page provides the shared development explanation for the series.

- Each project has its own repository containing its source code and usage instructions.
